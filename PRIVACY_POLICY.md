# Privacy Policy for Sankey Diagram Community Visualization

**Last Updated:** January 15, 2026

## Overview

The Sankey Diagram Community Visualization ("Visualization") is a data visualization tool for Google Looker Studio developed by Alvaro Padilla.

## Data Collection

This Visualization does **not** collect, store, or transmit any personal data or user information.

### How the Visualization Works

- The Visualization runs entirely within Google Looker Studio's iframe environment
- All data processing occurs locally in your browser
- No data is sent to external servers
- No cookies are set by this Visualization
- No analytics or tracking is implemented

### Data Handling

- The Visualization only accesses data that you explicitly configure in Looker Studio
- Data is processed solely for the purpose of rendering the Sankey diagram
- No data is cached or persisted by the Visualization itself

## Third-Party Services

This Visualization uses the following open-source libraries:
- D3.js (BSD 3-Clause License)
- d3-sankey (BSD 3-Clause License)

These libraries do not collect any user data.

## Google Looker Studio

Your use of this Visualization within Google Looker Studio is also subject to [Google's Privacy Policy](https://policies.google.com/privacy).

## Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted to this page with an updated revision date.

## Contact

For questions about this Privacy Policy, please open an issue on our GitHub repository or contact Alvaro Padilla.
